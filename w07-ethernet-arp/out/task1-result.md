# 7주차 Task 1 실행 결과

`task1_switch.py`의 학습 스위치를 구현하고 제공된 검증을 실행했다. VS Code에서도 `--verify` 인수로 실행해 같은 결과를 확인했다.

## 구현 내용

- 출발지 MAC 주소를 수신 포트 및 마지막 수신 시각과 함께 저장한다.
- 알려진 목적지는 해당 포트로만 전달한다.
- 브로드캐스트와 미등록 목적지는 수신 포트를 제외한 모든 포트로 전달한다.
- 전달 포트 목록은 오름차순으로 반환하며, 수신 포트로는 되돌려 보내지 않는다.
- 같은 MAC 주소가 다른 포트에서 나타나면 최신 포트로 갱신한다.
- 새 프레임의 시각을 기준으로 마지막 수신 후 300초를 초과한 항목을 제거한다. 시뮬레이션 시간이 프레임으로 주어지므로 별도 실시간 타이머는 사용하지 않는다.

| 검사 | 실제 결과 | 판정 |

| 미등록 목적지 flooding | `[1, 2, 3]` | 통과 |
| 등록 목적지 단일 포트 전달 | `[0]` | 통과 |
| A, B 주소 학습 | A → 0, B → 2 | 통과 |
| 브로드캐스트 전달 | `[1, 2, 3]` | 통과 |
| 수신 포트로 재전송 방지 | `[]` | 통과 |
| B의 포트 이동 반영 | A로 전달 `[0]`, B의 새 포트 `3` | 통과 |
| 오래된 항목 삭제 | 400초 시점에 A가 테이블에 없음 | 통과 |

실행 명령:

```bash
python task1_switch.py --verify
python test_tasks.py --task 1
```

첫 번째 실행은 `all ok`, 두 번째 실행은 `1 passed, 0 failed, 0 skipped`로 종료했다. 두 번째 실행의 1 passed는 위 7개 검사를 묶은 Task 1 검사 한 건을 뜻한다.

현재 정리한 범위는 Task 1이며 Task 2, Task 3의 완료 결과는 포함하지 않는다.
